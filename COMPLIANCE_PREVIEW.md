## Manual Requirements

The following aspects of each standard require manual implementation beyond what OpenForge scaffolds:

### Navigation (NAVIGATION_STANDARD)
- Route definitions matching the platform's routing system
- Deep link registration (Universal Links, App Links, protocol handlers)
- Back stack business logic (custom back navigation beyond defaults)
- Command palette content (searchable commands)
- Platform navigation animations and transitions

### Data Storage (DATA_STORAGE_STANDARD)
- Actual database/schema creation and migration scripts
- Export implementation (serialization of user data to JSON)
- Import implementation (parsing exported JSON back into storage)
- Sync logic (if implementing cloud sync)
- Conflict resolution UI
- Backup scheduling

### Security & Privacy (SECURITY_PRIVACY_STANDARD)
- Permission request dialogs with platform API calls
- Authentication flow integration (OAuth, sign-in)
- Secrets management (keychain/keystore integration)
- Privacy policy content (legal text, not boilerplate)
- Telemetry opt-in/opt-out toggle UI

### Performance (PERFORMANCE_STANDARD)
- Bundle size optimization (code splitting, tree shaking)
- Image optimization pipeline
- Font loading strategy
- Performance regression CI integration
- Low-end device testing
