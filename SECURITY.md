# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in {App Name}, please report it privately.

**Do not** file a public GitHub issue. Instead, send a detailed report to:

- **Email:** {security@email}
- **PGP key:** {link to public key, if applicable}

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- The potential impact.
- Any suggested remediation (if known).

You will receive a response within {X} business days. We will keep you informed of the progress toward a fix and release.

## Supported Versions

| Version | Supported |
|---|---|
| Latest | ✅ |
| Older | ❌ — upgrade to the latest version |

## Scope

This security policy covers the {App Name} application and its official distribution channels. It does not cover dependencies unless the vulnerability is introduced by our use of them.
