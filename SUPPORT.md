## Getting help

| Channel | How |
|---|---|
| Issues | Open an issue in the repository (include the version, Windows build, and what you did) |
| Diagnostics | In the app: **General → Export Diagnostics** and paste the output into your issue |
| Data location | `%APPDATA%\org.kovina.opentime\opentime.sqlite` |

## Guidelines

- Include your **OpenTime version** (see General → About) and **Windows version/build**.
- Describe **what you did, what you expected, and what happened**.
- If it's a crash, export diagnostics and attach them.

## Security

Report security issues privately via [SECURITY.md](SECURITY.md) — do not file a public issue.
